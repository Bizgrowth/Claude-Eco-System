Golden rules

    SOPs

    GitHub sync

    Connect once per device and your priorities and to-dos sync everywhere as GitHub Issues (labels dash:priority and dash:todo).

    The token is stored only in this browser, never in the repo. Use a private repo for sync issues. If you lose a phone, revoke the token at github.com/settings/tokens.

    Backup

    Offline copy of your current lists.

    Install on your phone
    • iPhone: open in Safari → Share → Add to Home Screen.
    • Android: Chrome → ⋮ → Install app.
    Change links & repos: edit data/config.json in the repo (or ask Claude Code to do it). GitHub data refreshes every ~20 min via the “Refresh dashboard data” Action.
